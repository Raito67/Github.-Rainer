# Jose Rainer Sarmiento — Portfolio

A responsive student portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — design and responsive layouts
- `script.js` — mobile navigation menu
- `assets/profile.jpg` — supplied profile photo

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
